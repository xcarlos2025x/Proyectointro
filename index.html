Java

Java es un lenguaje de programación extremadamente transferible que se utiliza en diversas plataformas y tipos de dispositivos, desde smartphones hasta televisores inteligentes . Se utiliza para crear aplicaciones móviles y web, software empresarial, dispositivos del Internet de las Cosas (IoT), juegos, big data, aplicaciones distribuidas y basadas en la nube, entre otros.

Python

En resumen, Python es un lenguaje de programación de alto nivel, interpretado y de código abierto, conocido por su legibilidad y facilidad de uso. Es versátil y se utiliza en una amplia variedad de aplicaciones, desde desarrollo web hasta ciencia de datos.

PHP

PHP es un lenguaje de programación para desarrollar aplicaciones y crear sitios web que conquista cada día más seguidores. Fácil de usar y en constante perfeccionamiento es una opción segura para aquellos que desean trabajar en proyectos calificados y sin complicaciones.
